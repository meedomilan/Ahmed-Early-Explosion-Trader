# Ahmed Early Explosion Trader

بوت مستقل لمراقبة جميع عقود Binance USDⓈ-M USDT Futures.

## الفريمات
- 15m: اكتشاف مبكر
- 1h: تأكيد أساسي
- 4h: سياق واتجاه أكبر

## المراحل
- 🟡 استعداد مبكر جدًا
- 🟠 استعداد مؤكد
- 🔥 بداية الانفجار

## التشغيل على Railway
1. أنشئ مستودع GitHub جديدًا وارفع جميع الملفات.
2. في Railway اختر Deploy from GitHub Repo.
3. أضف Variables الموجودة في `.env.example`.
4. أنشئ Volume واربطه بالمسار `/app/data` حتى تبقى قاعدة البيانات بعد إعادة النشر.
5. افتح الدومين الذي ينشئه Railway:
   - `/` لوحة الحالة
   - `/health` فحص الصحة
   - `/opportunities` الفرص
   - `/stats` الإحصائيات
   - `/checkpoints` نقاط الفحص

## ملاحظات مهمة
- لا ينفذ البوت أي صفقة.
- النسب أولًا درجات شروط، وليست احتمالات مثبتة.
- يفحص جميع العقود بالبيانات الخفيفة، ثم يجلب OI ودفتر الأوامر للمرشحين الأقوى لتجنب تجاوز حدود API.
- CVD وReal Delta تقديريان من بيانات الشموع/التداولات العامة المتاحة، وليسا Footprint حقيقيًا من منصة مدفوعة.


## تغييرات v2 EARLY
- الفحص الافتراضي كل 15 ثانية.
- المرحلة المبكرة لا تنتظر كسر البنية.
- تثبيت الإشارة في قراءتين متتاليتين لتقليل الإشارات الكاذبة.
- منع إرسال BUY وSELL معًا لنفس العملة إذا لم يكن الفارق واضحًا.
- منع مطاردة الشمعة إذا امتدت أكثر من حد ATR المحدد.
- زيادة وزن CVD وReal Delta وOI وOrder Book وAbsorption.


## تغييرات v3 SMART
- حفظ تاريخ آخر 8 قراءات لكل عملة واتجاه.
- اكتشاف استمرار OI وCVD وOrder Book بدل الاعتماد على لقطة واحدة.
- حساب Smart Money Persistence Score.
- المرحلة المبكرة لا تُرسل إلا بعد 3 قراءات متتالية افتراضيًا.
- رفض الإشارة عند انقلاب الدلتا والدفتر وOI ضد الاتجاه.
- إضافة بصمة الأموال الذكية داخل رسالة Telegram.
